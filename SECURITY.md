# Security

Stambha runs before your operating system starts, with full access to the machine's memory and disks, so security
problems matter.

**Please report them privately**, not in a public issue:
[report a vulnerability](https://github.com/garvitsurana271/stambha/security/advisories/new) on GitHub.

Include what you found, how to reproduce it, and what it lets an attacker do. You'll get an answer, and credit in the
fix unless you'd rather not.

Examples of what counts: a way for macOS or a USB device to escape into the host or another device's memory, a path
that writes to a disk outside the macOS partition, or personal data (serials, MAC addresses, network names, keys)
reaching a log or the network.
